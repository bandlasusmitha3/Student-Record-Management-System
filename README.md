# Student Record Management System

A console-based Java application designed to manage student records efficiently. The system allows users to add, view, update, and delete student information through a simple menu-driven interface.

## Features

- Add new student records
- View all student records
- Update student information using Student ID
- Delete student records using Student ID
- Store student ID, name, and marks
- Display appropriate messages when records are not found

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Scanner
